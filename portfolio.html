현재 보유 수량

파이어니어 전략으로 들고 있는 종목만 입력하세요. 매매를 마친 뒤 조정 화면에서 “보유 수량 갱신”을 누르면 자동으로 바뀝니다.

변경 기록

    파이어니어에서 바로 불러오기

    아래 버튼을 북마크바로 끌어다 놓으세요. 파이어니어 리스트 화면에서 이 북마크를 누르면 화면의 종목 표를 읽어 이 앱으로 바로 가져옵니다. 일부만 가져오고 싶으면 그 부분을 드래그로 선택한 뒤 누르세요.

    파이어니어 → 계산기

    폰에서는 아무 페이지나 북마크한 뒤, 북마크 편집에서 주소를 복사한 코드로 바꾸면 됩니다.

    거래 단위

    증권사에서 주문 가능한 소수 자릿수입니다. 목표 수량을 이 자리에서 반올림해 매수·매도 수량을 계산합니다.

    시세 (Finnhub)

    예상 매수·매도 금액을 보려면 Finnhub API 키를 넣으세요. 포트폴리오 앱에서 쓰시던 키를 그대로 쓰시면 됩니다.

    기기 간 동기화 (Firebase)

    포트폴리오 앱의 firebaseConfig를 그대로 붙여넣으세요. 데이터는 같은 데이터베이스의 pioneerRebal 노드에 따로 저장되어 기존 앱과 섞이지 않습니다.

    데이터

    목표 리스트와 체크 표시를 지웁니다. 보유 수량은 그대로 남습니다.

    새 리스트 붙여넣기

    파이어니어 화면에서 종목 표를 통째로 복사해 붙여넣으세요. 티커와 주식 수를 자동으로 읽고, 비중은 배분 금액으로 계산합니다.
